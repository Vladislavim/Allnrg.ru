# SEO-контент-бриф для точечного усиления страниц услуг

Дата: 2026-05-31

Источник: `seo/wordstat-clean.json`, `seo/keyword-clusters.json`, `seo/seo-map.json`.

Семантика WordStat использована осторожно: в выгрузке есть нерелевантные инфозапросы и ассоциации, поэтому в рекомендации ниже взяты только фразы, которые подходят инженерно-проектной компании и не превращают страницы в SEO-простыни.

## Общий принцип

- Не добавлять длинные SEO-блоки.
- Не менять стиль сайта.
- Усиление делать точечно: 1-2 короткие фразы на страницу.
- Не использовать неподтвержденные обещания: "гарантируем", "100%", "официальная аккредитация", "СРО", "лицензия", если нет подтверждения.
- Основной фокус: проектирование, проектная и рабочая документация, BIM, инженерные системы, экспертиза, обследование, расчет конструкций.

## Страницы, выбранные для локального усиления

После дополнительного отбора в локальную правку взяты не все услуги, а только страницы, которые выглядят слабее или слишком похожи по смыслу на соседние посадочные:

## Приоритет внедрения

1. `objecti-infrastrukturi.html` - слабее всего сформулирован первый экран, есть странная скобка в H1.
2. `projectirovanie-med-ucherezhdenii.html` - много образности, не хватает инженерных маркеров.
3. `projectirovanie-objectov-turizma.html` - красивая страница, но коммерческий интент слабоват.
4. `projectirovanie-barov-restoranov.html` - хороший интент, нужно убрать риск "гарантии".
5. `projectirovanie-selskogo-lesnogo-hozyastva.html` - нужно усилить отраслевую конкретику и убрать "гарантию".
6. `raschet-konstrukcij.html` - добавить расчеты нагрузок/прочности/устойчивости, убрать "гарантию".
7. `negosudarstvennaya-ekspertiza.html` - оставить сопровождение экспертизы без обещания результата.
8. `laboratoriya-kontrolya.html` - аккуратнее с "официальностью", если нет подтверждения.

## Что не нужно добавлять

- Длинные блоки "ключ через запятую".
- Отдельные SEO-тексты внизу страницы.
- Скрытый текст.
- Неподтвержденные регионы, лицензии, СРО, клиенты, кейсы.
- Частотный мусор из WordStat вроде общих справочных запросов, городских справочников и случайных ассоциаций.

## Итог

Для полноценного усиления достаточно внедрить по одной короткой фразе на страницу услуги и заменить несколько рискованных обещаний на инженерно-точные формулировки. Это даст больше пользы, чем добавление больших SEO-текстов: страницы станут точнее по интенту, но визуально и стилистически останутся близкими к текущей версии.
